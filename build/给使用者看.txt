WaifuCode · 小依
===============================================================

一个住在桌面右下角的二次元助手。她有心情、会唱会跳、能陪你玩，
还能替你去跑 Claude Code 干活。


-------------------------------------------------------------
先说清楚：哪些开箱即用，哪些要你自己装东西
-------------------------------------------------------------

【不用装任何东西，双击就能玩】

  · 她本人（会呼吸、眨眼、眼神跟着你鼠标走）
  · 摸头、戳她、拖着走
  · 跳舞（右键 → 跳一个）
  · 唱歌 / 放音乐（放你自己的歌，见下面）
  · 一起玩：猜情绪、猜歌、番茄钟
  · 换模型、换发型、换贴图、调表情
  · 语音说话（用的是微软在线语音，只要能上网就行）

  这些一分钱不花。


【要她"干活"和"聊天"，得先有 Claude Code】

  派活、私聊、她主动搭话 —— 这些是真的在调 Claude，
  所以你电脑上必须有 Claude Code 命令行工具，而且登录过。

  没装的话：她照样能唱能跳能陪你玩，只是派活那块点了会告诉你没找到。

  装法看官网：https://claude.com/claude-code
  装完在任意终端敲一句 claude 能进去，就算好了。

  这部分是按你自己的 Anthropic 账号计费的，跟这个桌宠没关系。


-------------------------------------------------------------
装 / 卸
-------------------------------------------------------------

【安装版】WaifuCode-x.x.x-安装版.exe
   双击，可以自己挑装到哪个盘。装完开始菜单和桌面都有快捷方式。
   卸载走系统的"应用和功能"。

【免安装版】WaifuCode-x.x.x-免安装.zip
   解压到任意文件夹，双击里面的 WaifuCode.exe 就行。
   要搬家/删掉，整个文件夹拷走或删掉即可，注册表里什么都不留。


-------------------------------------------------------------
你的东西存在哪儿
-------------------------------------------------------------

免安装版：exe 旁边的 data\ 文件夹里
安装版：  也是安装目录下的 data\；万一装在了写不进去的地方
          （比如 C:\Program Files），会自动改用
          C:\Users\你\AppData\Roaming\WaifuCode

不确定的话：右键托盘那个小头像 → "打开数据目录"，直接就打开了。

里面有：
  config.json   设置（也能直接改）
  waifu.log     日志，出问题先看它
  music\        把你自己的 mp3 丢这儿，她就能放来听、跟着跳
  sessions\     她对每个项目的记忆

想换个地方存：设一个环境变量 WAIFU_HOME 指向你想要的文件夹。


-------------------------------------------------------------
音乐
-------------------------------------------------------------

安装包里**不带任何歌**（版权是你自己的事）。

把 mp3 / m4a / wav / ogg / flac 丢进 data\music\ 就行。
想让她踩准拍子，在文件名里用方括号写上 BPM：

    某首歌 [128].mp3

不写也能跳，她会按 118 拍摇，幅度还是跟着音量走。


-------------------------------------------------------------
用不起来先看这几条
-------------------------------------------------------------

· 桌面上什么都没出现
    窗口是全透明的，崩了也看不出来。去数据目录看 waifu.log。

· 说话没声音
    语音走的是微软在线服务，断网就没有。设置里也能整个关掉。

· 派活点了说找不到 claude
    Claude Code 没装，或者没在 PATH 上。装完重启一次桌宠。
    也可以设环境变量 WAIFU_CLAUDE_BIN 直接指到 claude.exe。

· 终端窗口长得难看 / 开不出来
    有 Windows Terminal 就用它，没有会回落到老式控制台。
    Windows 11 自带；Windows 10 可以去微软商店装一个。

· 她一直不说话
    她是有情绪才开口的，不是聊天机器人。想聊天右键 → "跟她聊聊"。


更详细的玩法看安装目录里的「玩法说明.md」。
