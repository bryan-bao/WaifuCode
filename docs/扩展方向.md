# 扩展方向：接更多模型、让其他部门也用得上

> 2026-08-31。起因是一句话：「现在只支持 claude 和 codex 的 cli，有没有可扩展的方向让其他模型也能用到？
> 现在只有程序能用到，其他部门几乎不会用这个。」
>
> 这份是 14 个人分头查完（代码摸底 1 人、市面上 8 家 CLI + 直连 API 各 1 人、部门视角 3 人、
> 最后 1 人通读挑刺）之后我整理的。每条能力判断都有来源；写「没查到」的就是真没查到。
> 决策还没做，这是给你挑的。

---

## 一、先说三个结论

**1. 「换模型」这件事，最便宜的路不是接新 CLI，是给 Claude Code 换后端。**
Claude Code 认 `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN` 两个环境变量，DeepSeek / 智谱 / Kimi / 千问
现在都提供 Anthropic 兼容接口。桌宠所有起进程的地方（终端线、无窗口派活、私聊、搭话）都是
`env: { ...process.env }` 原样透传——**代码里一处都没处理过这两个变量**（核实过，grep 为零）。
所以：设置页加「接入地址 / 密钥」两栏、塞进 env，约 80 行，**派活和陪聊两半边同时换成国产模型**，
一个新 CLI 都不用接。公司统一发密钥、不用每人开浏览器登海外账号，也是这 80 行顺带解决的。

**2. 「其他部门用不起来」不是缺功能，是三样东西：黑窗口、程序员黑话、装机门槛。**
部门视角那组列了 35 条办公类的活（发票 OCR 成台账、按模板批量出 offer、12 段视频转码抽封面、
一稿改三平台……），**27 条今天就能派，一行代码不用改**——Claude Code 本来就是「能读写文件、
跑脚本、看图」的通用代理，不只会写代码。卡住的是：行政看到弹出来的终端窗口会当成中了病毒；
面板上「项目目录 / 分支 / 权限模式 / Opus 5」四个词没一个是他该懂的；第一步装 Node.js 就劝退了。

**3. 有一个比以上都急的坑：发给别人的安装包，根本没装那 5 条 hook。**
桌宠靠 `~/.claude/settings.json` 里的 5 条 hook 才知道终端里在发生什么。装它的是 `npm run install-hooks`，
**只在开发机手动跑过**——`main.js:3721` 的注释原话「装不装 hook 是另一回事」。打包版启动时不装，
安装器也不装。所以别的机器上她只是个不会说话的动画：状态灯、护栏、「等你确认」、回来汇报**全部静默失效**，
而且没有任何报错。个位数行改动（首启调一次 `hooks/install.js`，它已经是幂等的）。后面所有「推给部门」
的方向都建在这个坑上，先补它。

## 二、接更多模型：三层路线，按便宜到贵

### 第 1 层：换后端（80 行，推荐先做）

| 做什么 | 怎么做 | 得到什么 |
|---|---|---|
| 设置页加「接入地址」「密钥」 | 写进 config，四处 spawn 的 env 里加 `ANTHROPIC_BASE_URL` / `ANTHROPIC_AUTH_TOKEN`（codex 是 `OPENAI_BASE_URL` / `OPENAI_API_KEY`） | 国产模型直接给 Claude Code 用；公司发钥匙不用登录 |
| 单价表挪进 config | 现在 `cost.js` 按 Anthropic 官方价折算 usage；第三方端点回的 usage 常缺缓存字段甚至全 0 | 认不出的模型显示「未计价」，**不显示 $0**（那是骗人） |
| 密钥抹除 | `test-journal.js` 守着「流水里不许出现密钥」，日志/时间线打印报错时要把 key 抹掉 | 不泄密 |

两个没实测的点：① 搭话用的 `--json-schema` 是靠工具调用实现的，第三方 Anthropic 兼容口对 tool_use
支持参差，搭话可能整段回落本地台词；② Claude Code 是闭源客户端，指向第三方模型的条款公司层面要过一眼。

### 第 2 层：陪聊直连 HTTP（约 400 行，可选）

陪聊那半边（私聊 / 搭话 / 周记 / 回来汇报）**根本不需要 CLI**：任何 chat-completions API 都满足它的
全部要求——一次请求出文本、历史我们自己存（`chat.js` 的 `this.msgs` 本来就全量落盘）、system 消息
原生换人设、`response_format: json_object` 要结构化、**压根不传 tools 字段就物理上没工具**（比 Claude 的
`--tools ''` 还干净）。

查了五家：DeepSeek、通义千问（DashScope 兼容模式）、智谱 GLM、月之暗面 Kimi、本地 Ollama——
**同一个 POST 形状，一个通用客户端一把全接**，只差 base_url / key / model 三个配置项。
价格量级（人民币 / 百万 token，输入 / 输出）：DeepSeek v4-flash 3 / 9（非高峰五折）；
千问 / 智谱 / Kimi 同一量级；Ollama 本地免费（RTX 3070 跑得动）。

有了第 1 层之后，它剩下的独有价值只有三样：**不装任何 CLI 也要她开口、离线 Ollama、每轮省掉起 CLI
进程的开销**。值得做，但不是「接国产模型」的必经路。算钱口径要重新量（没有 prompt 缓存、历史每轮
全量回灌，「成本 56% 是缓存写」那套结论对它不成立）。

### 第 3 层：接第三家 CLI（300 + 500~800 行，3~5 天，只在前两层不够用时立项）

先说代码现状：**"codex" 在 `terminals.js` 里出现 148 次、`main.js` 64 次**，五处白名单
（`DISPATCH_AGENTS`、`mobile.js` 的三元、`panel.js`、`mobile.html`、`terminals.open`）各自独立，
不认识的值静默归 claude。再直接往里堆第三家就是把这些分岔再抄一遍。所以第三家之前要先做
「归位」：`src/agents/` 下一张登记表，每家导出统一形状（bin / launchArgs / perm / hooks / transcript /
keys …），main 和 terminals 只认接口——约 300 行、零功能变化。

挑刺组对这个接口纠了两处：**hook 接口不能照 codex 画**（codex 是命令行 `-c` 注入 + 信任哈希，
8 家里只有它这样；Qwen / Gemini / Copilot / Kimi / goose 全是「写进用户级配置文件」，跟 claude 的
`hooks/install.js` 同款，主路应是 `install()`）；**远程放行不能只靠送键**（OpenCode 是 ←→+Enter、
goose 是箭头菜单，都不是单键；但它们的 hook 里能直接回 allow/deny，接口得留这条路）。

**八家打分**（按她需要的能力：会话 id 能不能我们发 / 能不能 resume / 有没有事件 hook / 档案在哪 /
报不报钱 / 确认键 / 能不能接国产或本地模型；查于 2026-08-31）：

| CLI | 活跃度 | id 我们发 | resume | 事件 | 档案 | 钱 | 确认键 | 国产/本地 | 结论 |
|---|---|---|---|---|---|---|---|---|---|
| **Qwen Code**（阿里） | 很活跃，v0.22.3 8/28 | **有** `--session-id` | 有 | hook 照抄 Claude Code | jsonl | token | **1 / Esc** | **主场** | **首选**。跟 claude 那条线长得最像，工作量约 codex 一半；硬 `--json-schema` |
| **Copilot CLI**（GitHub） | 很活跃，1.0.82 8/29 | **有** | 有 | 全，`permissionRequest` 可直接 HTTP 回桌宠 | events.jsonl（格式无承诺） | token | 1/2/3 Esc | BYOK 四个 env | **备选**。缺 `--system-prompt`，陪聊别用它 |
| **OpenCode** | 很活跃，v1.18.25 8/28 | 不能（插件 `session.created` 认领） | 有 | **进程内 JS 插件**，全，钩子里能直接放行 | SQLite | 有但自定义 provider 有坑 | ←→+Enter，非单键 | 内置 DeepSeek/GLM/Kimi/通义 | 能接，事件比 codex 强；三个硬伤都在 id / 键位 / 档案格式 |
| **Kimi Code CLI**（月之暗面） | 很活跃，v0.39.1 8/28 | 不能 | 有 | 20 个事件，比 Claude 还全 | 无 token | 不报 | 1 / Esc | 主场 + 任意 OpenAI 兼容 | **交互模式传不了初始 prompt**（契约必备项），v1 不接 |
| **goose**（Linux 基金会） | 很活跃，v1.48 8/27 | 不能 | 有 | 部分（无 PreCompact、无等确认） | SQLite | **直接报美元** | 箭头菜单 | 要自填地址 | 能接，量≈codex |
| Gemini CLI（Google） | 仓库活跃但 **2026-06 个人账号被踢**，主推 Antigravity | 源码有、文档说不行（未实测） | 有 | hook 照抄 Claude | jsonl | token | 1-9 / Esc | **不支持** | 接口最像 Claude，商业面塌了，不接 |
| Cursor CLI | 活跃，闭源绑订阅 | 它发 | 有 | 有，但等确认无信号 | SQLite 不公开 | token | y / n | **不支持 BYOK** | 不接 |
| Aider | 降速（半年没发版、一人独撑） | 无 | 伪 resume | **无 hook** | markdown | stdout 报钱 | y / n | 全支持 | 2023 年那代设计，不接 |

**一台机器装多家会互相串**（选型自己查出来的）：Cursor CLI 会合并读取 Claude Code 的 settings.json
里的 hooks——装了 Cursor 的机器会拉起桌宠的 5 条 notify.js，载荷字段对不上、被当成「你在别的窗口
手动干活」计进心情。多家都改终端标题，`focus-window.ps1` 按标题精确匹配送键会对不上。
再加 CLI 更新频繁（codex 改档案格式已经栽过一次、Kimi 一个月 8 版），发给部门的机器要钉版本。

## 三、让其他部门用起来

### 零代码起步包（半天运维，先做）

- 每个部门一个根目录（`D:\部门\财务`、`D:\部门\行政`…），派活面板的「项目目录」本来就不限于代码仓库。
- 点 📝 打开这个目录的小抄，上半段（她永远不动的那半）写三样：这个部门的活通常怎么做、**输出统一放 out/**、
  公司工具在哪（ffmpeg 在 `E:\chao-tool\VideoTool`、VoiceboxCLI 的用法）。之后在这个目录派活她开口就懂行。
- **财务 / 人事两条规矩必须一起写**：「表格类先写脚本算，只把汇总结果读回来」（1200 行 Excel 直接读进
  上下文 = 几毛到几块钱，还全上云）；「身份证号、银行卡、薪资明细派活前先脱敏」。
- D 盘预装一个 venv（openpyxl、python-docx、python-pptx、pdfplumber、Pillow、pandas），路径写进全局
  `~/.claude/CLAUDE.md` 一句「Python 用这个，别另装」——不然每台机器第一次都等 pip，还装到 C 盘。
- **Claude Code 官方 Skills**（三组人都没提，挑刺组补的）：Anthropic 官方有 docx / xlsx / pptx / pdf 技能，
  就是「怎么用 python-docx / openpyxl 处理 Office 文件」的现成 SOP，放进 `~/.claude/skills`（codex 认
  `~/.codex/skills`）。部门规矩也可以写成 SKILL.md 按部门装，比每个目录一份小抄更通用、更省 token。
  这一条直接消掉部门那组判定的「Word / Excel 是产品边界」。

### 办公模式（2~3 天，一个开关 + 一张字典，不是第二套面板）

一个不写代码的同事第一次双击 WaifuCode.exe，会按顺序卡在这些地方：

| 卡在哪 | 现在 | 办公模式 |
|---|---|---|
| 装 | 先装 Node.js，再浏览器登海外账号，claude 首启还有一屏 onboarding 等人按键 | `installAgent` 加分支走 Claude Code **原生安装器**（不要 Node）；「公司发的钥匙」填进设置 → env；预写 `~/.claude.json` 跳过 onboarding |
| 「项目目录」「D:\你的项目」 | 办公同事没有「项目」 | 「要处理的文件夹」，占位「比如 D:\周报\8月」；或干脆固定一个「工作台」目录不让选 |
| 任务框示例「把登录页的表单校验补上」 | 第一眼就告诉他「这不是给我用的」 | 换办公示例：「把这个文件夹里的 12 份周报合成一份汇总，做成表格」 |
| ⚙ 横条「Claude Code · Opus 5 · 自己判断」 | 四个选项没一个是他该决定的 | 整条隐藏，管理员在设置里定死；面板只留二选一「只看不改，给我建议 / 可以动这个文件夹里的文件」 |
| **两个按钮都弹黑窗口** | 「后台干」还会闪 0.25 秒再缩到任务栏 | 只留「交给她」，走**已经写好的无窗口派活**（`sessions.js`，`cfg.mode==='headless'`，只是设置里没暴露） |
| 中途「等你确认」→ 跳到黑窗口里 y/n | 办公同事到这儿就死了 | 无头模式配 `--allowedTools` 白名单（Read/Write/Edit/Glob/Grep + `Bash(python *)`），不在名单的直接拒，**永远不弹确认** |
| 结果去哪了 | 原地改文件，没有「产出」概念 | 系统提示里定规矩「新做的一律放 `<文件夹>\小依产出\`，原文件不覆盖」，做完自动打开那个文件夹 |
| 一整套终端语言 | 「这轮完事了」「压缩过 N 次」「异常退出 code 1」「动了 63 次工具」 | 一张 ~40 条文案字典：正在做 / 做完了 / 没做成（点开看原因）/ 做了 N 步 / 活太长了建议拆开 |
| 手机端那排 `/resume` `!git status` 和按键板 | 全是救开发会话用的 | 只留：文件夹、📤 传照片、「交给她」、她手上的活、产出列表 |
| 人设「你懂编程」 | 汇报念「哪个项目、改了几个文件、点我看现场」 | 「办公室里帮大家处理文件的小助手」；汇报「XX 做完了，出了 N 个文件在产出里，有 M 件没做成」 |

**一个必须先定的矛盾**（挑刺组核实代码抓出来的）：无窗口派活那条路默认带 `--setting-sources project`
（用户级 5 条 hook 不加载）又设 `WAIFU_SELF`（notify.js 见到就退），两道闸叠着，
**「跑偏了喊我」那道护栏在无头路上是死的**。所以办公模式的边界不能靠护栏，只能靠 Claude Code 原生的
`--allowedTools` 白名单 + `permissions.deny`。同一个参数大概率也让 `~/.claude/skills` 不加载，
要么把 `isolateSettings` 关掉，要么技能放项目级——做之前先实测。

另外三件：① 无头派活现在**只许 claude**（`main.js:3137`），部门机器若只装 codex，办公模式整个不可用；
② 目录约定已经三套（手机上传落 `inbox/`、拖文件走分流、办公模式又要 `小依产出/`），先统一成一个
「工作台」；③ 手册不用整本重写，在最前面加一节「办公同事三步用法」，办公模式下「说明书」按钮直接跳那儿。

### 边界与部署（财务 / 人事上机的前提）

- **现有护栏是「开发者防手滑」，不是安全边界**：它刻意只喊不拦（notify.js 800ms 超时等不到裁决），
  而且**一个字都不管 Read**——财务最怕的「工资表读进 prompt 发出去」它管不了。
- 真正的闸是 Claude Code 原生 `permissions.deny`（`Bash(rm:*)`、`Read(//C:/Users/**)`、`Bash(curl:*)` 这类，
  被拒的调用模型根本执行不了）。`hooks/install.js` 已经在写用户级 settings.json，同一处顺手写一份
  「受管模式」deny 表；更狠一层是 `C:\ProgramData\ClaudeCode\managed-settings.json`，用户改不了。
- 固定「工作台」目录 + 手机端 `mobile.tunnel` 锁死（一个按钮就能把派活口开到公网）+ 口令一键作废。
- 审计：她的流水（`journal.js`）刻意洗掉路径和密钥，不是审计。真审计在 `~/.claude/projects` 的 jsonl 里，
  会话 id 是桌宠自己发的所以能精确认领「哪些是她派的」，集中归档就行。
- 多台部署的真痛点是账号 / 钱 / 策略分散，不是执行分散。集中三样就够：**内网 LLM 网关**（LiteLLM / one-api
  一类，按子密钥限额计费审计）、config 受管字段脚本下发、**局域网更新包加签名校验**（`updates.js` 手册自己
  写了「公网必须先加签名」——现在共享盘谁能改谁就能给全公司推包）。
- 「一台服务器集中派活、大家用手机」**不建议**：放行 / 叫停 / 看窗口 / 按键全依赖本机桌面，没用户概念、
  没并发隔离，桌宠本体在服务器上毫无意义——那是另一个产品的一半，不是移植。

## 四、排序（价值 ÷ 工作量，挑刺组定的，我同意）

**第一梯队 · 小改动、都是地基**

1. **打包版首启自动装 hook**（个位数行）——现在每台发出去的机器监督全是死的
2. **设置页「密钥 / 接入地址」→ env**（~80 行）——公司发钥匙、免登录、换国产模型，三件一起
3. **零代码起步包**（半天运维）——27 条办公活今天就能派
4. **原生安装器分支 + 跳过 onboarding**（小~中）——非开发机第 0 步不再死
5. **官方 Skills 当办公技能**（复制目录 + 小抄一句）——Word / Excel 边界消失
6. **硬边界 deny 表 + 工作台目录 + 隧道锁死**（小~中）——财务 / 人事上机前提

**第二梯队 · 中等**

7. 办公模式（2~3 天；依赖 2、4、6，先定上面那个矛盾）
8. 「用谁来干」按机器上装了什么自动隐藏 + 五处白名单收成一处（小；现在非程序员会点 Codex 然后报「帮我装」）
9. 「常用活」钉住清单（100~150 行；「每月考勤汇总」「合格证改日期」变成点一下）
10. 内网网关 + 受管字段下发 + 更新包签名（大部分是运维；多台才有价值）
11. `E:\chao-tool` 的本地 OCR、PdiagramTool 批量套改抽成命令行（OCR 半天、套改一天；解锁发票 / 名片 / 资产标签 / 合格证，图片不上云）
12. HTTP 陪聊层（1~1.5 天；不装 CLI / 离线 / 省钱）

**第三梯队 · 大或低值**

13. 适配器归位（~300 行，单独做没收益，只给 14 铺路）
14. 第三家 CLI——**非做不可就 Qwen Code**，备选 Copilot CLI BYOK；Kimi / OpenCode / goose 先不接，
    Gemini / Cursor / Aider 不接。**做完第 2 条实测后仍不够用才立项**
15. 定时派活（「每周一自动出周报」；今天用 Windows 任务计划程序跑 `claude -p` 能凑合）
16. 集中派活服务器——不做

**一句话**：先做 1，紧跟着 2。这两条加起来不到一百行，但「监督在别人机器上是活的」和
「不用海外账号也能跑」就都有了；第三家 CLI 在这之后价值归零，除非 Claude Code 的兼容口哪天不稳。
