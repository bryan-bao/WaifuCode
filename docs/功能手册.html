01 · 快速上手

三步开始

  1. 启动她开发机在项目目录跑 npm start；拿到安装包的直接双击 WaifuCode.exe。她会出现在桌面右下角。
  2. 双击她打开派活面板（上图）。填个项目目录、说句人话，点「让她后台干」或「开终端我看着」，她就开工了。
  3. 右键她全部功能都在这个菜单里：派活 / 聊天 / 一起玩 / 跳舞 / 唱歌 / 换打扮 / 设置。
先说清依赖：她的功能分两半。唱跳、摸头、小游戏、换装、说话的语音——什么都不用装，双击就能玩。派活和聊天——真的在调 AI，机器上要装好 Claude Code（或 Codex CLI）并登录，按你自己的账号计费。没装不会崩，她会明说「这台电脑上没找到」。

02 · 日常互动

你能对她做什么

你的动作她的反应花钱吗
点她一下主动说一句现想的话（看时间、心情、你手头的活）约 1.5 分
按住她的头眯着眼往你手的方向蹭；摸太久（6.5 秒）会躲开抗议；连着点很多下三档递进：害羞 → 受用 → 烦不花
拖着她走「欸欸欸——！」，头发裙子跟着甩不花
鼠标移动眼睛跟着你转；你不动了她会走神看别处不花
走开 15 分钟再回来抬头看你一眼说句话；走开超 90 分钟会闹小脾气不花
点她头顶的气泡💬 的跳进私聊接着聊；🖥↗ 的调出那个终端看现场不花
她正对着你时点她那是「在等你确认」——直接跳到那个终端不花
点项目名旁的 📝打开这个项目的小抄（她攒的，你能改能清）不花

03 · 她的状态是真的

不是随机播表情

精力、心情、亲密度是三个真实数值，每一次变化都有来由：卡在报错里会越来越烦躁；一遍过会得意（那股劲儿能挺四分钟）；连轴转会累——肩膀塌下去、呼吸变慢、眼皮往下掉；半天没人理会闹脾气；半夜会困、会催你睡。精力的回法：你人不在电脑前她就在歇着，跟关不关机没关系，一夜不碰电脑第二天她精神满格。

同一个状态写在三层上，扫一眼就知道：脸（换表情）、底噪（眼皮开合、呼吸快慢）、骨架（肩膀塌不塌、低不低头，常驻一直挂着）。外加十几个演两秒就收的情绪动作：开心蹦两下、得意叉腰、生气往前逼、鄙夷抬下巴侧身、无聊整个人往下泄。

她开始记日子了

认识满一周、满一个月、满一百天；一起干完第 10 个、第 100 个活；连着七天来找她……到了这些数她会自己冒一句话、配个动作。不会烦你：一天最多响一个，她忙着、你玩着的时候不响，响过的永远不重复。台词是提前写好的，一分钱不花。

04 · 派活干真事

两种派法

「让她后台干」——开一个最小化的真终端，不弹出来烦你，但现场全在，跑挂了随时调出来看。「开终端我看着」——直接开在你面前，随时接管一起改。两种窗口一模一样，只差开完收不收进任务栏。Ctrl+Alt+W 随时把面板叫出来。

她全程盯着，用身体汇报

那边在发生什么她身上
顺利推进微微前倾，像在看手上的活
连着报错整个人绷起来、头压低、呼吸变快
卡住不动歪着头停在那儿
在等你确认转过来正对着你——这时候点她一下直接跳到那个终端
做完一段弹气泡说原话 + 语音念关键的 + 记进小抄和流水；点气泡直接看现场
要干危险的事动手之前转过来喊你：改到项目外的文件、整份重写太多、rm -rf / git reset --hard 这类回不来的命令。只喊不拦，点气泡跳过去自己按 Ctrl+C

这些全是本地判断和预置台词，盯着不花钱。几个终端一起跑时她身上显示最要紧的那个（跑偏了 > 等确认 > 报错 > 卡住 > 正常）。

每个项目一张小抄

每次开终端都是干净的一条会话（不自动读旧记录，又慢又贵还多半不是你要的那条）。但她会给每个项目攒一张小抄：每段活干完那句汇报顺手记进去，只留最近 6 条。下次开工她第一句就知道上回干到哪儿。小抄你能看能改（点 📝），上半截留给你写规矩，她永远不动。带进终端每次约 3 分钱，封顶——对比以前整段旧对话读回来是 3 毛到 1 块 5 还上不封顶。

多条线、接着聊、再来

  • 同一个项目能同时开好几条线，一条查登录一条查支付，互相不串；线名自动从任务里取，任务栏上一眼分得开
  • 关掉的线留在列表上（压暗），带着最后那句汇报；点「接着聊 ↻」回到那条线，她记得之前聊的；点「再来」照原样再派一次全新的
  • 你在窗口里自己敲 /resume 换了会话她也跟得上——「接着聊」接的就是你真正在用的那条，账也算到正确的窗口头上
  • 每条线下面列着她动过的文件（点一下在资源管理器定位）和这条线烧的钱——按官方单价折算，包月订阅不真扣，但它是「这段活值多少」最诚实的刻度

面板还有四套皮肤

右上角下拉随手换，换完就记住。面板永远出现在她所在的那块屏幕上、贴在她旁边；点任务时终端窗口会真的弹到面板前面。

05 · 用谁来干：Claude 与 Codex

没装 Claude 的电脑，选 Codex 一样全须全尾

面板上「用谁来干」下拉选一次就记住，派活、私聊、搭话全跟着走。两边的差别如实列在这儿：

能力Claude CodeCodex
派活、开终端、多条线有有
做完一段来汇报（气泡+语音+小抄）实时有，慢几秒
停下来等你确认时喊你有有
「接着聊」真接上旧会话有有
金额（按官方单价折算）有有
私聊 / 摸头搭话有有（每轮约贵 6 倍）
动手前的报警（护栏）有没有——它的档案是干完才写的，拦不住
面板上选模型四档可选跟它自己配置走

Codex 窗口开出来会印明这次给了什么权限（面板那个下拉会盖过你 ~/.codex/config.toml 里的设置，只管这一次）。「先出方案」在 Codex 上的真实含义是「只读 + 什么都问你」——它没有先出方案这个模式，说明文字也跟着换了说法。

想要动手前那道保险、或者活儿要跑很久没人盯着：用 Claude 派更稳。日常两边随意，体验一致。

06 · 私聊与 17 种表情

跟真人聊天一样：会坏笑、会翻白眼、会真的生气

右键 →「跟她聊聊」，或面板右上角「私聊」。单独一条会话，跟任何项目不沾边；她手上真的没有工具，不可能在扯闲篇时顺手改了你的代码。你在聊天框说的每句话，桌面上那个她同步在演：17 种表情配上身体动作——生气不只是眉毛压下来，是整个人朝你逼过来；鄙夷是抬下巴侧过身；无聊是往下泄一口气。聊完回头戳她，她记得刚才聊了什么。

情绪来了头顶会冒符号。表情参数在桌宠尺寸下先天含蓄（厚刘海的模型眉毛全被头发盖住、嘴就几个像素），所以情绪一来她头顶会短暂冒一个动漫符号：生气 💢、难过 💧、好奇 ❓、慌了 💦、困了 💤、开心 ✨、坏笑 ⭐、鄙夷「哼」、无聊「…」。同一情绪几秒内只冒一次，不花钱，设置 →「她」里可以关。

骂她「破程序」，她真的会生气——「行吧，那我这破程序不装了」；紧接着讲个冷知识，她又忍不住好奇：「我还没消气呢，但这个我确实想知道」。

聊着聊着她就动起来了

聊天里让她跳个舞、唱首歌，她会真的去做——说「那我跳个温柔的」和她真的跳慢舞，是同一个决定。想换性格：聊天窗口右上角「性格」，改完点「重开一段」生效。

07 · 陪你玩（全都不花钱）

玩法说明
跳舞不是循环播动作，是按拍子现算的编舞：腰摆、头歪、肩弹、踏步、甩手，头发裙子物理自然甩。跟着音乐段落变：前奏轻晃、副歌放开
唱歌放你自己丢进 music/ 的歌，嘴型跟真实音量走。拍子她自己听（也认文件名 [128BPM] 标记）
哼唱她现编几句词唱出来（这个走语音合成，算说话）
猜情绪她摆个表情你猜是什么——表情和身体一起演，才猜得出来
猜歌从你的 music/ 里放 8 秒，你猜是哪首
番茄钟25 分钟专注，她陪着，到点提醒
音乐的规矩：这里不预置任何歌，也永远不会去音乐平台抓歌。把你自己的音频丢进 music/ 文件夹就行。点一首没有的歌，她会明说没有、报出手上有哪几首。

08 · 换人换装

13 个角色随便换，换人不用重启

设置 →「形象」。Hiyori（默认双马尾）、Mao（魔女画家，唯一能真换装的：摘帽子脱外套收法杖）、Haru、名执尽、Ren Foster、千岁、泉、春伞积木、猫（两种花色）、Mark 君、汪子、Rice、海梦（三种配色）。全部会跟着心情变脸；猫靠耳朵和尾巴演戏，生气会炸毛。

换装两条路，可以叠着用

  • 换身打扮——藏掉部件 = 真的脱掉一件（Mao 专属）；Hiyori 能把双马尾放下来
  • 换套贴图——真的重画布料。把图丢进 models/<模型>/skins/ 就出现在菜单里；要动好几张图的开个文件夹按号放 texture_NN.png

同一个人的几身配色算一个人（海梦三身、猫两色都在「换套贴图」里），列表不会冒出同名同脸的。想自己做花纹：npm run probe-uv 能把无缝花纹铺到指定部件上、保留原图明暗，褶皱阴影一根不少。

09 · 花钱的地方，一笔一笔说清

花钱大约多少
后台派活、终端任务按用量，一场长会话可能几十美元——面板上每条线都标着
私聊Claude 约 1 分/轮；Codex 约 3 毛5/轮（订阅内不真扣）
点她时主动搭话约 1.5 分/次
开终端带小抄约 3 分/次，封顶
不花钱（随便用）
跳舞、唱歌、三个小游戏、摸头拖动、视线跟随、换人换装、说话的语音（微软 Edge 免费合成）、全程盯活的表情姿态、跑偏报警、记日子、面板上「今天」那栏的账
一句话记住：「她说什么」要调 AI 才花钱，「她怎么动」全是本地算的，零成本。

10 · 设置、数据、打包给朋友

设置在哪

齿轮图标（鼠标移到她身上右下角浮出来）或右键 →「设置」。四页：形象（换人、她的大小 ×0.6~×1.6 拖着滑杆当场变、位置微调）、声音（TTS 开关音色）、干活（权限模式、监督开关、要不要念、更新源与分发点）、她（情绪动作、情绪符号、眼神、色调）。

数据存在哪

免安装版在 exe 旁边的 data\；安装版也在安装目录（装到写不进的地方会自动挪到 AppData）。不确定就右键托盘头像 →「打开数据目录」。里面是设置、日志、你的歌、她对每个项目的记忆——整个文件夹拷走就等于搬家。

打包发给别人

  1. 双击「打包.bat」第一步先问这次改动多大（大改/中改/小改，版本号自动递增），再自检、打包，完事告诉你产物在哪。
  2. 挑一个发过去安装版.exe（可选盘符、有快捷方式）或 免安装.zip（解压即用，删掉文件夹就干净了）。
  3. 跟对方说清唱跳玩什么都不用装；派活聊天要装 Claude Code 或 Codex 并登录，按对方账号计费。没装也不用对方折腾——点派活时她会在报错旁给个「帮我装」按钮，点一下她自己装好（电脑上要有 Node.js）。安装包里一首歌都不带。

11 · 版本与更新

面板标题旁常驻当前版本号。更新不走服务器——发包的那台电脑自己就是更新站，同一局域网里的桌宠自己来拿。

收更新的人（朋友那边）

  1. 填一次地址设置 → 干活 →「更新源」，填发包机给的那串（形如 192.168.1.5:47200，端口带在冒号后面，没有别的端口设置）。旁边「现在查一次」能立刻试通不通。
  2. 之后全自动开机 20 秒查一次、每 4 小时再查，一次就一张几百字节的小纸条。有新版她喊一声（同一版只喊一次），面板版本号变成「有新版 x.y.z · 点我更新」。
  3. 点一下装完下载 → 校验（传坏的包当场删掉重报）→ 拉起安装器，她自己退出让路。装完重开就是新版，设置、记忆、歌全在。中途失败她不退出，面板写明原因。

发更新的人（你这边）

  1. 开分发点设置 → 干活 → 打开「把这台电脑当更新分发点」。设置页直接写着分发文件夹在哪、让朋友填什么地址（几块网卡全列出来，哪个通用哪个）。第一次 Windows 问防火墙，选「允许」。
  2. 丢包即发布打好的安装版 exe 丢进分发文件夹就完了。里面躺着多个时期的版本也没关系——按文件名里的版本号挑最大的发，不看文件时间，绝不会把老包发出去，也不会把人降级。
  3. 版本号自动涨打包第一步就问这次改动多大：大改 1.0.0 起新篇 / 中改第二段 +1 / 小改尾段 +1（回车默认）。号不动的包发了等于没发——朋友那边全靠号分辨新旧。

一条要记得的边界：这套是给自家人内网用的，局域网里没有身份验证——别在网吧、公司大网这种公共网络上开分发点。检查更新不花钱。

12 · 疑难杂症

现象怎么回事
终端里突然满屏乱码多半是跑的某个 .bat 里有 chcp 936 改了整个窗口的代码页。救急：/exit 后敲 chcp 65001 再 claude -c；根治要改那个 bat
后台派活时屏幕闪一下正常。wt 没有「最小化启动」，只能开出来再收，约 0.25 秒
改了性格没生效人设是开场写死的，点「重开一段」（Codex 私聊则下一句就生效）
Rice 站得偏右偏小不是坏了，她那张原图本来就横着画、人在右半边
点了更新说被拦了多半杀毒软件拦了安装器。她会写明包下到哪儿了，去那儿手动双击就行
「帮我装」装完还是报没装npm 全局目录不在 PATH 里（挪过 prefix 的机器会这样），把它加进 PATH 或重启桌宠再试
出问题想查日志数据目录里的 waifu.log；涨到 8MB 自动砍前一半，不会撑爆盘

常用命令：npm start 启动 · npm test 心情自检 · npm run sessions 看各项目会话 · npm run demo-song 生成试唱曲。
